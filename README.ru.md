# Фикс медиа-окна Telegram для niri

[English version](README.md)

Окно просмотра фото и видео в Telegram Desktop на [niri](https://github.com/niri-wm/niri)
ведёт себя как в Windows: обычное плавающее окно поверх остальных. Его можно
таскать мышью на любой монитор и при этом спокойно писать в чат. Следующее
фото открывается на том же мониторе, в том же месте и того же размера.

## Что было не так

* **Только крестик, окно не утащить.** Просмотрщик в полноэкранном режиме
  Telegram. Кнопки окна берутся из системной раскладки кнопок, а частое
  значение по умолчанию `appmenu:close` оставляет только ×, поэтому
  переключиться в оконный режим нечем. Заголовков niri не рисует, так что и
  хвататься не за что.
* **Фокус скачет обратно на фото.** Пока просмотрщик «на весь экран» на том же
  мониторе, что и чат, Telegram возвращает фокус на него при каждом клике в
  главное окно.
* **Мигание и лаги.** Telegram постоянно просит у niri полный экран. Скрипты,
  которые силой возвращают окно в плавающий режим, бесконечно с ним воюют.
* **Всегда открывается по центру текущего монитора.** Telegram каждый раз
  создаёт новое окно просмотрщика, а приложение под Wayland не может само
  выбрать, где оно появится.

## Как работает фикс

1. **Оконный режим Telegram (один клик, один раз).** У просмотрщика есть
   нормальный оконный режим. В нём Telegram перестаёт просить полный экран и
   воровать фокус, а тёмный фон вокруг фото работает как заголовок. Нажатие
   там запускает обычное перемещение окна (`xdg_toplevel.move`), которое niri
   поддерживает для плавающих окон, в том числе между мониторами.
2. **Правило окна niri** открывает просмотрщик плавающим (такие окна всегда
   поверх тайловых) и отклоняет его первый запрос на полный экран.
3. **`telegram-media-place`**, крошечная пользовательская служба. При
   закрытии просмотрщика записывает его монитор, позицию и размер в
   `~/.config/niri/telegram-media.kdl` (`open-on-output` +
   `default-floating-position` + фиксированный размер). niri сам перечитывает
   файл, и следующее окно сразу **открывается** на месте. После появления окно
   никто не двигает, поэтому курсор не прыгает и войны с Telegram нет. Один
   постоянный сокет к niri: ни опроса, ни запуска процессов.

## Что нужно

* niri с поддержкой `include` в конфиге (проверено на niri 26.04)
* Telegram Desktop (проверено на 7.3.1, обычный или Flatpak, app id `org.telegram.desktop`)
* `python3` и пользовательская сессия systemd
* `gsettings`, только если в просмотрщике есть один крестик (см. шаг 2)

## Установка

```bash
git clone https://github.com/freakkxd/Telegram-Media-Window-Niri-Fix-tmwnf-
cd Telegram-Media-Window-Niri-Fix-tmwnf-
./install.sh
```

Установщик:

* делает бэкап `config.kdl` (`config.kdl.bak-telegram-media-<дата>`);
* ставит `~/.local/bin/telegram-media-place` и пользовательскую службу
  `telegram-media-place.service` и включает её;
* дописывает в конфиг блок правил из [`niri/telegram-media-viewer.kdl`](niri/telegram-media-viewer.kdl)
  между метками `>>> telegram-media-window-niri-fix >>>`;
* запускает `niri validate` и возвращает бэкап, если niri не принял конфиг.

### Один раз: переключить просмотрщик в оконный режим

<img src="docs/images/windowed-mode.svg" width="100%" alt="Средняя кнопка в правом верхнем углу просмотрщика">

1. Откройте любое фото и поведите мышью: в правом верхнем углу появятся
   кнопки окна. Нажмите среднюю («развернуть/восстановить»).
2. Если окно стало на весь экран, нажмите её ещё раз: теперь это окно.
   Telegram запомнит выбор.

Там только ×? Ваша раскладка кнопок прячет остальные. Запустите скрипт,
сделайте то, что он скажет, и он сам вернёт раскладку обратно:

```bash
./scripts/show-maximize-button.sh
```

## Как пользоваться

* **Переместить:** зажмите левую кнопку мыши на тёмном фоне вокруг фото и
  тащите, на любой монитор. Само фото и кнопки управления работают как обычно.
* **Изменить размер:** `Mod` + правая кнопка мыши в niri, тянуть. Размер
  тоже запоминается.
* **Писать в чат:** просто кликните в чат и печатайте, фото останется открытым.
* **Открыть снова:** следующее фото или видео откроется там, где закрыли прошлое.

## Telegram на другом языке

Правило находит просмотрщик по заголовку окна: из коробки это
`Media viewer` (английский) и `Просмотр медиа` (русский). Для другого языка
откройте фото и посмотрите заголовок:

```bash
niri msg windows
```

И установите с вашим заголовком (это регулярное выражение):

```bash
TG_MEDIA_TITLE_RE='^(Media viewer|Ваш заголовок)$' ./install.sh
```

Если фикс уже стоял, сначала запустите `./uninstall.sh`, чтобы блок в
конфиге переписался с новым заголовком.

## Удаление

```bash
./uninstall.sh
```

Удаляет службу, скрипт, блок в `config.kdl` (с бэкапом) и
`telegram-media.kdl`. Чтобы вернуть просмотрщику полный экран, снова нажмите
в нём кнопку «развернуть».

## Если что-то не так

```bash
systemctl --user status telegram-media-place
journalctl --user -u telegram-media-place -f
cat ~/.config/niri/telegram-media.kdl
```

* **Просмотрщик всё ещё на весь экран.** Он ещё не в оконном режиме, см. шаг
  «Один раз».
* **Открывается по центру монитора.** Ещё нечего вспоминать: передвиньте окно
  и закройте его один раз. И проверьте, что заголовок совпадает с
  регулярным выражением (`niri msg windows`).
* **Запомненный монитор отключён.** niri откроет окно на текущем мониторе.

## Ограничения

* В niri нет режима «на всех рабочих столах»: окно живёт на своём рабочем
  столе. Переключите этот монитор на другой стол, и окно уйдёт вместе со своим.
* niri рисует только рамку фокуса, без заголовка. Окно тянется за тёмный фон,
  а не за полоску заголовка.
